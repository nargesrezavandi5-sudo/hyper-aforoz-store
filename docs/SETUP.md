# راهنمای راه‌اندازی محلی (Development)

## پیش‌نیازها
- Python 3.8+ (توسعه و آزمایش روی 3.8.8 انجام شده است)
- Node.js 18+ (آزمایش روی v24)
- npm

## ۱) بک‌اند (FastAPI + SQLite)

```bash
cd backend
pip install -r requirements.txt

# (اختیاری) تنظیم متغیرهای محیطی
copy .env.example .env      # ویندوز
cp .env.example .env        # لینوکس
# مقدار تصادفی SECRET_KEY (حداقل ۳۲ نویسه) و رمز قوی ADMIN_PASSWORD را تنظیم کنید.
# فایل .env هنگام اجرای بک‌اند به‌صورت خودکار خوانده می‌شود.

# ساخت حساب مدیر و داده‌های نمونه (فقط بار اول)
python -m app.seed

# اجرای سرور
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

سرور روی `http://localhost:8000` اجرا می‌شود.
مستندات تعاملی API: `/docs`

## ۲) فرانت‌اند (Vite + React + TypeScript + Tailwind)

```bash
cd frontend
npm install
npm run dev
```

پنل مدیریت: `http://localhost:5173/#/admin`
صفحه نمایش تلویزیون (لینک مشترک برای همه تلویزیون‌ها): `http://localhost:5173/#/display`

همه تلویزیون‌ها همان آدرس `/#/display` را باز می‌کنند — توکن یا ثبت‌نام برای هر نمایشگر لازم نیست.
لینک و QR از پنل مدیریت ← «نمایشگرها» قابل کپی است.

## ۳) ورود به پنل

- نام کاربری اولیه از `ADMIN_USERNAME` و رمز اولیه از `ADMIN_PASSWORD` خوانده می‌شوند.
- رمز را در فایل `.env` تنظیم کنید؛ فایل seed آن را در خروجی چاپ نمی‌کند.
- این حساب هنگام اجرای `python -m app.seed` ساخته می‌شود. اگر از قبل حسابی وجود دارد، رمز آن را از پنل تغییر دهید.

## ۴) داده‌های نمونه

اسکریپت seed شش محصول نمونه با تصویر SVG آزمایشی و یک نمایشگر آزمایشی می‌سازد.
که به‌وضوح در تصاویرشان «تصویر آزمایشی» ثبت شده و با داده‌های واقعی قابل تفکیک‌اند و حذف‌شدنی‌اند.

## ۵) variables محیطی مهم (backend/.env)

| متغیر | توضیح |
|---|---|
| `SECRET_KEY` | کلید امضای JWT — الزامی، حداقل ۳۲ نویسه تصادفی |
| `ADMIN_USERNAME` / `ADMIN_PASSWORD` | حساب مدیر اولیه |
| `ALLOWED_ORIGINS` | دامنه‌های مجاز CORS (دامنه واقعی را اضافه کنید) |
| `TOKEN_EXPIRE_HOURS` | اعتبار نشست مدیر |
| `MAX_IMAGE_MB` | حداکثر حجم آپلود تصویر |
| `DATABASE_PATH` / `MEDIA_DIR` | مسیر دیتابیس و تصاویر |
